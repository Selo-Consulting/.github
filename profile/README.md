# Selō Consulting

**AI-enabled workflow automation and KPI analytics for growing businesses — secure by design.**

Selō (Selo Consulting Inc.) is a Toronto-based consultancy. We make the tools your team already uses work harder: we customise your existing workflows, add AI where it saves real time, and give leadership a clear, trustworthy view of the numbers that matter.

## What we offer

- **Workflow customisation, not replacement.** We start from how your business already runs — Microsoft 365, SharePoint, Teams, your line-of-business systems — and automate around it. No rip-and-replace, no new platform to learn.
- **Config-driven KPI indexes.** Your KPIs are defined in configuration, not buried in code or spreadsheets. Change a target or a formula without a rebuild, and trace every number back to its source.
- **AI agents that do the legwork.** Agents gather data, draft reports, and flag exceptions — while the figures themselves are always calculated by tested code, never invented by a language model.

**First focus:** construction SMEs (20–500 staff) running on Microsoft 365 and Azure — schedule variance, cost variance, safety incident rates, and the reporting that ties them together.

## How we're different

Security isn't an add-on we sell separately. It's built into every delivery:

- **Agents never hold secrets.** Credentials stay in *your* Azure Key Vault, reached through managed identities and Microsoft Entra ID via a credential broker.
- **Your infrastructure, your data.** Solutions run in your own tenant. You own the keys, the logs, and the code we deliver.
- **Read-only first.** We start with read access and widen permissions only when there's a clear, approved need.
- **Every action audited.** What an agent did, when, and with which identity — always on record.
- **Numbers from code, not the LLM.** KPI calculations are deterministic and testable; AI handles language, not arithmetic.
